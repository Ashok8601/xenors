Frequently Asked Questions

What is the price?

The listed system price is ₹50,000. Installation, additional cameras, PLC integration, control-box hardware and commissioning can change the final project price.

Can it stop a forklift?

The AI layer can generate a stop-request output. Actual stopping must use the forklift's approved control interface and be validated for the application.

Can it stop an assembly line?

Yes, the system can generate a PLC or relay signal when a person enters the configured critical zone. The line controller performs the engineered response.

Does it need wearable tags?

No wearable tag is required for the camera AI to identify a visible person.

Can I use multiple cameras?

Yes. Multi-camera configurations can cover front/rear forklift views or multiple industrial safety zones.

What happens if the camera goes offline?

A well-designed installation should expose camera and AI health status so loss of protection can generate a visible fault and approved fallback action.
