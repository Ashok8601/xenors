Build the mental model behind Python NumPy Tutorial

Standardizing three sensor columns can be expressed as one vectorized operation: subtract the column means and divide by the column standard deviations.

  • NumPy arrays store homogeneous data in contiguous multidimensional structures, enabling fast vectorized numerical operations.
  • Shape, axis and broadcasting rules explain most array behavior and most beginner mistakes.
  • Vectorization replaces many Python loops with operations implemented in optimized native code.
  • Always inspect dtype before arithmetic because integer truncation, object arrays or silent casting can change results.

Example 1 · Baseline example
# NumPy Tutorial · example 1
import numpy as np
X = np.array([[10., 2.], [14., 5.], [18., 8.]])
mean = X.mean(axis=0)
std = X.std(axis=0)
X_scaled = (X - mean) / std
print(X_scaled)
