Build the mental model behind Data Cleaning in Python

A customer-age column containing -1, 999 and text values should first be converted safely to numeric, then validated against a plausible range. Invalid values can be set to missing and handled according to the analysis goal.

  • Cleaning is not deleting inconvenient rows; it is making data quality decisions explicit and reproducible.
  • Missing values can mean unavailable, not applicable or genuinely absent, and those cases should not be treated identically.
  • Outlier handling depends on context: a rare but valid transaction is different from a sensor error.
  • Keep raw data immutable and record every cleaning rule so another analyst can reproduce the dataset.

Example 1 · Baseline example
# Data Cleaning in Python · example 1
import pandas as pd

df['age'] = pd.to_numeric(df['age'], errors='coerce')
df.loc[~df['age'].between(0, 110), 'age'] = pd.NA
df = df.drop_duplicates(subset='customer_id')
print(df['age'].isna().mean())
