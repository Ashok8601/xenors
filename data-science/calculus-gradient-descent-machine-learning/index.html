Interpret Calculus & Gradient Descent in Machine Learning Explained before reaching for a formula

For a one-parameter model y_hat = w*x, the gradient tells you whether increasing or decreasing w would reduce squared error. Repeating the update gradually moves w toward a value that better fits the data.

  • A derivative measures local rate of change, and a gradient collects partial derivatives for a multivariable objective.
  • Gradient descent updates parameters opposite the gradient to reduce a loss function.
  • A learning rate that is too large can overshoot the minimum; one that is too small can make training unnecessarily slow.
  • Feature scaling can change optimization speed because elongated loss surfaces create inefficient zig-zag updates.
