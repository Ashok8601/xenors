Understand the role of data types in the data-science workflow

A fraud-detection system may combine structured transaction amounts, semi-structured device events and unstructured support notes. The modeling pipeline should keep the sources separate long enough to validate each one before joining features.

  • Structured data fits a defined schema such as rows and columns, while unstructured data includes text, images, audio and other formats without a fixed tabular shape.
  • Semi-structured formats such as JSON and event logs carry keys or tags but can vary from record to record.
  • Measurement scale matters: nominal, ordinal, interval and ratio variables support different summaries and mathematical operations.
  • Before modeling, identify the unit of observation and data type because encoding a category as a number does not make it truly numeric.
