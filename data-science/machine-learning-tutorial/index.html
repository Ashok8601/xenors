Frame the prediction problem before choosing a model

For loan default prediction, you might compare logistic regression with a random forest using a time-aware split, inspect precision and recall at multiple thresholds, and choose a threshold based on the cost of missed defaults versus unnecessary reviews.

  • Machine learning learns patterns from examples, but the quality of labels, split strategy and evaluation often matters more than model complexity.
  • A baseline model provides the reference needed to decide whether a sophisticated algorithm adds real value.
  • Training performance alone is not evidence of generalization; evaluation data must remain separate from model fitting and tuning.
  • Error analysis should identify where the model fails so the next iteration targets a real weakness instead of random hyperparameter changes.

# ML workflow · example 1
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=.2, stratify=y, random_state=42)
model = LogisticRegression(max_iter=1000).fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))

Example 2 · Create a leakage-safe split
# ML workflow · example 2
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv('practice.csv')
target = df.select_dtypes('number').columns[-1]
X = df.drop(columns=[target]).select_dtypes('number')
y = df[target]
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)
print(X_train.shape, X_test.shape)
Output / checkpoint
ML workflow checkpoint 2: Training and test shapes are printed so the split is explicit.
Example 3 · Build a simple baseline
# ML workflow · example 3
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error

baseline=DummyRegressor(strategy='mean').fit(X_train,y_train)
pred=baseline.predict(X_test)
print('baseline MAE=', round(mean_absolute_error(y_test,pred),3))
Output / checkpoint
ML workflow checkpoint 3: The baseline score becomes the minimum standard a more complex model should beat.
Example 4 · Fit a transparent model
# ML workflow · example 4
from sklearn.linear_model import LinearRegression
model=LinearRegression().fit(X_train,y_train)
pred=model.predict(X_test)
print('model MAE=', round(mean_absolute_error(y_test,pred),3))
Output / checkpoint
ML workflow checkpoint 4: Compare model MAE with the baseline instead of judging the model in isolation.

errors=(y_test-pred).rename('residual')
