Frame the prediction problem before choosing a model

A fraud tree may split first on transaction amount, then device risk and time of day. A random forest averages many such trees so a single unstable split has less influence.

  • A decision tree recursively splits the feature space into regions that reduce impurity or prediction error.
  • Deep trees can memorize training data, so depth, leaf size and pruning control variance.
  • Random forests reduce variance by averaging many trees trained on resampled data with random feature subsets.
  • Feature importance from trees can be useful for exploration but should not be treated as causal explanation.

Example 2 · Create a leakage-safe split
# Decision Trees & Random Forest · example 2
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv('practice.csv')
target = df.select_dtypes('number').columns[-1]
X = df.drop(columns=[target]).select_dtypes('number')
y = df[target]
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)
print(X_train.shape, X_test.shape)

Example 3 · Build a simple baseline
# Decision Trees & Random Forest · example 3
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error

baseline=DummyRegressor(strategy='mean').fit(X_train,y_train)
pred=baseline.predict(X_test)
print('baseline MAE=', round(mean_absolute_error(y_test,pred),3))
