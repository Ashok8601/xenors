Choose the question before the chart

To compare delivery times across regions, a box plot quickly shows medians, spread and potential outliers, while a line chart is better for a daily trend over time.

  • Matplotlib provides low-level control over figures and axes, while Seaborn adds statistical defaults and DataFrame-friendly plotting.
  • Use explicit figure and axes objects for reusable plotting code instead of relying on global state.
  • Labels, units and readable scales matter more than decorative styling.
  • For dense data, transparency, aggregation or sampling can reveal patterns that an overplotted scatter chart hides.

Example 3 · Plot a distribution
# Matplotlib & Seaborn · example 3
num = df.select_dtypes('number').columns[0]
ax = df[num].plot(kind='hist', bins=12, edgecolor='black')
ax.set(title=f'Distribution of {num}', xlabel=num)
plt.tight_layout()

Example 4 · Compare groups
# Matplotlib & Seaborn · example 4
cat = df.select_dtypes(exclude='number').columns[0]
num = df.select_dtypes('number').columns[0]
print(df.groupby(cat)[num].agg(['count','mean','median']).round(2))
Output / checkpoint
Matplotlib & Seaborn checkpoint 4: The table shows group sizes beside mean and median so small groups are visible.

Questions specific to this lesson

How do I choose the right chart for Matplotlib and Seaborn?

Use explicit figure and axes objects for reusable plotting code instead of relying on global state.

What makes a visualization misleading for Matplotlib & Seaborn?

Truncated axes, inconsistent scales, hidden denominators and overloaded color can all change the story a reader takes from the same data.

What should I inspect before plotting for Matplotlib & Seaborn?

Check variable type, units, missingness, duplicates and sample size first. Many chart problems are really data-quality problems.

How do I make the chart reproducible for Matplotlib & Seaborn?

Keep the transformation and plotting code together, set explicit labels and save the output with fixed dimensions so another person can rebuild it.
