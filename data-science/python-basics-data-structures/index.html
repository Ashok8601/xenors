Build the mental model behind Python containers

When cleaning a survey dataset, a set can identify unique response categories, a dictionary can map abbreviations to full labels, a list can hold selected columns and a tuple can store an immutable coordinate pair.

  • Lists preserve order and are mutable; tuples are ordered but immutable; sets keep unique values; dictionaries map keys to values.
  • Choose a data structure by the operation you need most often, not by habit.
  • Dictionary lookups are useful for mappings, while sets are efficient for membership tests and deduplication.
  • Mutable containers can change in place, so copying behavior matters when the same object is shared across functions.
