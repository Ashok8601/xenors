Choose the question before the chart

For housing data, inspect price and area distributions, compare neighborhoods, plot price against area, check missing bedrooms and look for duplicate listings before training a price model.

  • A practical EDA pass checks shape, dtypes, missingness, duplicates, target balance and suspicious ranges before modeling.
  • Univariate plots explain distributions, while bivariate plots reveal relationships and potential leakage.
  • Segmented summaries can expose Simpson’s paradox or hidden subgroups that disappear in an overall average.
  • Keep an EDA log of anomalies and decisions so cleaning steps are traceable rather than ad hoc.

Example 1 · Baseline example
# Exploratory Data Analysis in Python · example 1
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('houses.csv')
print(df.info())
print(df.describe(include='all'))
print(df.isna().mean().sort_values(ascending=False).head())
df.plot.scatter(x='area_sqft', y='price', alpha=.4)
plt.show()

Example 3 · Plot a distribution
# Exploratory Data Analysis in Python · example 3
num = df.select_dtypes('number').columns[0]
ax = df[num].plot(kind='hist', bins=12, edgecolor='black')
ax.set(title=f'Distribution of {num}', xlabel=num)
plt.tight_layout()
Output / checkpoint
Exploratory Data Analysis in Python checkpoint 3: A histogram appears; look for skew, gaps and extreme values before summarizing the center.
Example 4 · Compare groups
# Exploratory Data Analysis in Python · example 4
cat = df.select_dtypes(exclude='number').columns[0]
num = df.select_dtypes('number').columns[0]
print(df.groupby(cat)[num].agg(['count','mean','median']).round(2))
Output / checkpoint
Exploratory Data Analysis in Python checkpoint 4: The table shows group sizes beside mean and median so small groups are visible.
Example 5 · Save a reproducible figure
# Exploratory Data Analysis in Python · example 5
fig, ax = plt.subplots(figsize=(8,4.5))
df[num].plot(kind='box', ax=ax, vert=False)
ax.set_title(f'{num}: spread and possible outliers')
fig.tight_layout()
fig.savefig('practice-chart.png', dpi=160)

What makes a visualization misleading for Exploratory Data Analysis in Python?

Truncated axes, inconsistent scales, hidden denominators and overloaded color can all change the story a reader takes from the same data.

What should I inspect before plotting for Exploratory Data Analysis in Python?

Check variable type, units, missingness, duplicates and sample size first. Many chart problems are really data-quality problems.
