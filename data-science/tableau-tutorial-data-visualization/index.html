Choose the question before the chart

A customer-retention dashboard might combine a cohort heatmap, monthly churn trend and segment filter so teams can move from an overall drop to the exact customer group behind it.

  • Tableau builds views by mapping fields to marks, shelves and filters rather than by writing chart code.
  • Dimensions usually slice data into categories, while measures are aggregated numerically.
  • Level-of-detail expressions are useful when the required calculation grain differs from the visual grain.
  • A dashboard becomes easier to use when filters, color and interaction all support the same analytical question.

Example 3 · Plot a distribution
# Tableau Data Visualization Tutorial · example 3
num = df.select_dtypes('number').columns[0]
ax = df[num].plot(kind='hist', bins=12, edgecolor='black')
ax.set(title=f'Distribution of {num}', xlabel=num)
plt.tight_layout()
Output / checkpoint
Tableau Data Visualization Tutorial checkpoint 3: A histogram appears; look for skew, gaps and extreme values before summarizing the center.
Example 4 · Compare groups
# Tableau Data Visualization Tutorial · example 4
cat = df.select_dtypes(exclude='number').columns[0]
num = df.select_dtypes('number').columns[0]
print(df.groupby(cat)[num].agg(['count','mean','median']).round(2))
Output / checkpoint
Tableau Data Visualization Tutorial checkpoint 4: The table shows group sizes beside mean and median so small groups are visible.
Example 5 · Save a reproducible figure
# Tableau Data Visualization Tutorial · example 5
fig, ax = plt.subplots(figsize=(8,4.5))
df[num].plot(kind='box', ax=ax, vert=False)
ax.set_title(f'{num}: spread and possible outliers')
fig.tight_layout()
fig.savefig('practice-chart.png', dpi=160)

Questions specific to this lesson

How do I choose the right chart for Tableau Data Visualization?

Dimensions usually slice data into categories, while measures are aggregated numerically.

What makes a visualization misleading for Tableau Data Visualization Tutorial?

Truncated axes, inconsistent scales, hidden denominators and overloaded color can all change the story a reader takes from the same data.

What should I inspect before plotting for Tableau Data Visualization Tutorial?

Check variable type, units, missingness, duplicates and sample size first. Many chart problems are really data-quality problems.

How do I make the chart reproducible for Tableau Data Visualization Tutorial?

Keep the transformation and plotting code together, set explicit labels and save the output with fixed dimensions so another person can rebuild it.
