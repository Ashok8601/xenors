Frame the prediction problem before choosing a model

For a small text-classification dataset represented by dense embeddings, a linear SVM can be a strong baseline because it handles high-dimensional decision boundaries efficiently.

  • A support vector machine finds a separating boundary with a large margin, which can generalize well in high-dimensional spaces.
  • The C parameter controls the trade-off between a wider margin and training errors.
  • Kernel functions allow nonlinear boundaries by comparing examples in an implicit feature space.
  • Feature scaling is important because distance and dot-product calculations are sensitive to measurement scale.

Example 2 · Create a leakage-safe split
# Support Vector Machines · example 2
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv('practice.csv')
target = df.select_dtypes('number').columns[-1]
X = df.drop(columns=[target]).select_dtypes('number')
y = df[target]
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)
print(X_train.shape, X_test.shape)

Example 3 · Build a simple baseline
# Support Vector Machines · example 3
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error

baseline=DummyRegressor(strategy='mean').fit(X_train,y_train)
pred=baseline.predict(X_test)
print('baseline MAE=', round(mean_absolute_error(y_test,pred),3))

Example 4 · Fit a transparent model
# Support Vector Machines · example 4
from sklearn.linear_model import LinearRegression

pred=model.predict(X_test)
print('model MAE=', round(mean_absolute_error(y_test,pred),3))
