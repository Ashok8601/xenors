Core interview questions and concise model answers

1. Explain bias and variance.

Bias is systematic error from an overly simple assumption; variance is sensitivity to the particular training sample. Diagnose with learning curves and compare training and validation error before changing complexity.

2. What is cross-validation?

Cross-validation estimates generalisation by rotating validation folds. Use stratified folds for imbalanced classification and time-aware splits for temporal data; never shuffle future data into the past.

3. L1 vs L2 regularisation?

L1 adds an absolute-value penalty and can drive coefficients to zero; L2 shrinks coefficients smoothly. Discuss scale, correlated features and why regularisation strength must be selected on validation data.

4. Why can accuracy be misleading?

A model predicting the majority class can score high accuracy on imbalanced data. Use confusion matrices, precision, recall, F1, PR-AUC or cost-weighted metrics depending on the decision.

5. How do tree models handle nonlinear relationships?

Decision trees partition feature space into regions and naturally model interactions. Ensembles such as random forests reduce variance while gradient boosting combines weak learners sequentially.

6. What is feature importance?

Importance is a model-dependent estimate of contribution, not causal proof. Prefer permutation importance or SHAP for richer analysis and check stability across folds.

7. How do you detect drift?

Monitor input distributions, prediction distributions, outcome metrics and segment-level performance. Distinguish covariate drift from concept drift because the response may be different.

8. What makes an ML system production-ready?

Version data and models, make preprocessing reproducible, define latency and reliability targets, log predictions safely, monitor drift and quality, and design rollback paths.

How interviewers go deeper

Expect follow-ups such as “why this metric?”, “what failed first?”, “how did you know the improvement was real?”, and “what would change at ten times the traffic?”. Revision checklist

  • Explain each concept in under 90 seconds.
  • Give one example from a real or portfolio project.
  • Name one failure mode and one measurement.
  • State when you would choose a simpler alternative.
  • Separate what you implemented personally from team work.
