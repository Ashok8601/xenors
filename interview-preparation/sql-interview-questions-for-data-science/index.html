Core interview questions and concise model answers

1. INNER JOIN vs LEFT JOIN?

INNER JOIN keeps matching rows from both sides; LEFT JOIN keeps all rows from the left plus matches from the right. Nulls reveal unmatched right-side records.

2. WHERE vs HAVING?

WHERE filters rows before aggregation; HAVING filters groups after aggregation. Use WHERE early when possible to reduce work.

3. What is a window function?

A window function computes values across related rows without collapsing them into one row per group. Common uses include ranking, running totals and lag comparisons.

4. ROW_NUMBER vs RANK vs DENSE_RANK?

ROW_NUMBER always assigns unique sequence numbers, RANK leaves gaps after ties, and DENSE_RANK does not leave gaps.

5. How do you find duplicates?

Group by the candidate key and filter groups with COUNT(*) greater than one, then inspect whether duplicates are exact or represent legitimate repeated events.

6. What is a CTE?

A common table expression names an intermediate query. It can improve readability and support recursion, though performance depends on the database optimiser.

7. How do you optimise a slow query?

Inspect the execution plan, reduce scanned data, verify indexes or partition pruning, avoid unnecessary columns, and simplify joins or repeated subqueries.

8. How do you calculate retention in SQL?

Define cohort and return event precisely, derive each user’s cohort date, join later activity by relative period, then divide returning users by cohort size.
