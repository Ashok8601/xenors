Debugging checklist for agentic ai

  1. Confirm the input, selector, key, path or identifier is the value you think it is.
  2. Inspect the runtime or browser state immediately before the failing step.
  3. Reduce the case until the problem still appears with the fewest moving parts.
  4. Test duplicate input explicitly instead of assuming the happy path covers it.
  5. Write down what fixed the issue so the same regression can be tested later.
